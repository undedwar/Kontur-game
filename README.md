🧩 Об игре
КОНТУР — это логическая головоломка, в которой тебе предстоит собирать электрические цепи, поворачивая проводники и прокладывая путь от источника энергии к цели.
Каждый уровень — новая задача, требующая внимания, логики и терпения.
✨ Особенности
⚡ Электрические цепи и энергетическая тематика.
🧠 Логические головоломки.
🔄 Поворот проводников для создания маршрута.
💡 Подсказки, помогающие найти решение.
⭐ Звёзды за прохождение уровней.
📈 Сохранение игрового прогресса в браузере.
📱 Возможность играть на телефоне и компьютере.
🌐 Не требует установки — игра запускается в браузере.
🎯 Как играть
Открой игру по ссылке выше.
Выбери доступный уровень.
Нажимай на проводники, чтобы поворачивать их.
Соедини источник энергии с конечной целью.
Пройди уровень и получи звёзды!
